Squad event controls

All 16 squads live on this page — no paging needed. Each panel holds its four players in a 2 × 2 grid. Press ELIM on a squad's last surviving player and the whole squad is out — nobody is left to revive the knocked players — and its placement is derived from the elimination order, so positions 9–16 score zero placement points automatically. Every position belongs to one squad only; type a placement any time to override it for re-verification.

ADMIN PROTECTION

Reset protection password

A special password that unlocks the master reset. It is separate from your administrator login password, so nobody at the desk can wipe the event by accident — and it is asked for again every time data is reset.

ADMIN PROTECTED ACTION

Reset tournament data

Every match, standings, MVP and top-fragger number recorded in this event is erased and the live controls go back to Match 01 · pre-show. This cannot be undone.

  • Live lobby: finishes, placements, damage, Alive/Knock/Eliminated
  • Live standings and current match points
  • Overall standings: total points, finishes, placement points, matches played
  • Finalized match history and the recent-results feed
  • MVP spotlight and overall top-fragger leaderboard
  • Match number, match status, broadcast scene and event log
  • Team registrations, approved rosters and group assignments

Set the password in Tournament setup → Reset protection password.
